# Format Library (formatlib)

The **Format Library** is the deterministic compiler and translation layer of DS ModelForge.
It translates canonical `ViewSpec` JSON definitions into SAP Datasphere native export JSON structures.

## Structure
- `v1_scaffold/`: Initial schema definitions and renderer for Datasphere format.
  - `schemas/viewspec_schema.json`: Strict JSON schema governing the `ViewSpec` intermediate format generated by the LLM.
  - `renderer.py`: Pure, deterministic rendering engine converting `ViewSpec` objects to Datasphere JSON representations (Graphical View, SQL View, Business Entity, Analytic Model).
  - `version_map.json`: Mapping of Datasphere releases to supported feature sets and schema versions.

## Design Principles
1. **Determinism**: The same `ViewSpec` always produces the exact same Datasphere JSON export.
2. **Decoupled from LLM**: The LLM writes canonical `ViewSpec`. The Format Library renders Datasphere JSON.
3. **Extensibility**: As new Datasphere export examples and versions are added, new scaffold versions or rules can be plugged in without changing the agent logic.
